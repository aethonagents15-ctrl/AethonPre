# AETHON — AI Agents Website

Static responsive multi-page site, ready for GitHub Pages or any static host.

## Pages
- index.html — Home
- agents.html — Agent roles
- solutions.html — Potential use cases
- demo.html — Interactive local workflow prototype (no AI backend)
- about.html — About
- docs.html — Documentation and FAQ

## Deployment
Upload all site files and the `assets` folder to the root of your GitHub repository, then enable Settings → Pages → Deploy from branch → main / root. No build process required.

## Important
This is a brand/concept website and front-end demonstration only. It does not implement agent execution, APIs, token deployment, minting, or wallets. X is set to https://x.com/AethonAgents.
